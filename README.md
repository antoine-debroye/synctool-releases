# SyncTool releases

Signed and notarized builds of SyncTool, a file sync app for macOS (Apple Silicon, macOS 13 or later).

**To install:** download the `.dmg` from the [latest release](https://github.com/antoine-debroye/synctool-releases/releases/latest), open it and drag SyncTool to Applications.

**Updates:** once SyncTool is installed, it updates itself. It checks this repository every few hours, downloads new versions in the background, and installs them the next time it quits.

This repository holds release builds only. The source code is kept elsewhere.
